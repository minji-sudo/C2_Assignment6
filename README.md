# 과제 06: 순차 탐색, BST, AVL 트리의 성능 비교

실행 시드: 42 (./a.out 42로 같은 결과를 재현할 수 있다)

0~1000 사이의 정수를 100번 생성해 배열, BST, AVL 트리에 같은 순서로 넣고 이미 저장된 중복값은 삽입하지 않았다.
이후 탐색 대상 50개를 새로 만들어 세 자료구조에서 같은 키를 탐색했다. 비교 횟수는 배열의 경우 확인한 원소 수, 트리는 방문한 노드 수로 집계하였으며, 과제 조건에 따라 AVL의 회전 및 높이 계산 연산은 제외하였다.


## 1. 실험 결과

| 항목 | Array (배열) | BST | AVL |
| :--- | :---: | :---: | :---: |
| 저장된 서로 다른 값 | 93 | 93 | 93 |
| 중복으로 삽입되지 않은 값 | 7 | 7 | 7 |
| 생성 비교 횟수 | 4,518 | 593 | 523 |
| 배열 길이 / 트리 높이 | 93 | 14 | 8 |
| 탐색 총 비교 횟수 (50개) | 4,443 | 365 | 335 |
| 탐색 평균 비교 횟수 | 88.86 | 7.30 | 6.70 |

- 50개 탐색 대상 결과: 성공 4개 / 실패 46개
- 세 자료구조 모두 동일한 4개의 키를 찾았으며, 트리의 노드 수가 93개로 배열 길이와 정확히 일치하여 세 구조에 동일한 데이터가 정상적으로 저장되었음을 확인하였다.

---

## 2. 분석

### 2-1. BST와 AVL 트리의 높이가 다른 이유

동일한 93개의 값이 동일한 순서로 입력되었음에도 불구하고 BST의 높이는 14, AVL 트리의 높이는 8로 명확한 차이를 보였다.

* 입력 순서 의존성: BST는 노드가 들어오는 순서대로 알맞은 위치에 연결할 뿐 구조를 재조정하지 않는다.
* 따라서 특정 방향으로 값이 몰려 들어올 경우 그쪽 가지가 길게 늘어나는 특성을 갖는다. 난수 입력 환경 특성상 극단적인 사선 트리가 되지는 않았으나, 일부 가지가 14단계까지 깊어졌다.
* 자가 균형 메커니즘: AVL 트리는 노드가 삽입될 때마다 지나온 노드들의 왼쪽/오른쪽 서브트리 높이 차이(Balance Factor)를 검사하며, 차이가 2 이상 벌어지면 LL, RR, LR, RL 회전을 통해 즉시 재조정한다.
*  이를 통해 모든 노드에서 높이 차를 1 이하로 유지하여 전체 높이를 로그 범위로 엄격하게 제한한다.
* 이론적 최소 높이와의 비교: 노드가 93개일 때 완전 이진 트리가 가질 수 있는 이론적 최소 높이는 7이다 (2의 7제곱은 128). AVL 트리는 최적값에 거의 수렴하는 높이 8을 유지하여 효과적으로 균형을 잡았음을 증명했다.

---

### 2-2. 트리의 높이가 탐색 비교 횟수에 미치는 영향

트리 탐색은 루트 노드에서 시작하여 하위 단계로 내려가며 진행되므로, 트리의 높이는 단일 탐색 시 발생하는 비교 횟수의 상한선(Worst-case)이 된다. 높이가 14인 BST는 탐색 시 최대 14번, 높이가 8인 AVL은 최대 8번까지 비교한다. 
실제 실험 결과 평균 비교 횟수는 BST 7.30회, AVL 6.70회로 AVL이 약 0.6회 적었으며, 총 비교 횟수에서는 30회(365회 vs 335회)의 차이가 났다.

높이 차이(14 대 8)에 비해 평균 비교 횟수의 차이가 크지 않았던 이유는 다음과 같다:
1. 평균 깊이의 영향: 평균 비교 횟수는 최장 가지의 깊이가 아니라 탐색 키가 거치는 경로 노드들의 평균 깊이에 좌우된다. BST에서 높이 14까지 깊어진 가지는 일부에 불과하며, 대다수의 노드는 더 얕은 위치에 존재한다.
2. 난수 입력의 특성: 완전 정렬 데이터와 달리 무작위 난수로 형성된 BST는 어느 정도 균형을 이루므로, 노드들의 평균 깊이가 AVL과 아주 크게 벌어지지는 않는다.
3. 실패 탐색의 주도: 전체 50개 탐색 중 46개가 실패 탐색이었다 (탐색 범위 0~1000 대비 저장 데이터 93개).
   * 배열: 정렬되지 않은 배열은 탐색 실패 시 93개 원소를 끝까지 순회해야 하므로, 실패 46회만으로 4,278회의 비교가 발생하였다 (성공 4회는 합계 165회, 평균 41.25회).
   *  이로 인해 순차 탐색의 평균 비교 횟수가 전체 배열 길이(93)에 매우 가까운 88.86회로 치솟았다.
   * 트리: 트리는 탐색에 실패하더라도 루트에서 리프 노드 하단(NULL)까지 내려가는 깊이만큼만 비교하고 종료하므로, 트리의 높이에 비례하는 수준에서 효율적으로 탐색을 마쳤다.

---

### 2-3. 세 자료구조의 생성 비용과 탐색 비용

* 생성 비용 (중복 검사 및 삽입):
  * 배열 (4,518회): 새 값을 넣을 때마다 중복을 확인하기 위해 기존 저장된 원소들을 처음부터 순차 검색한다. 저장된 93개 노드의 기본 생성 비용만 계산해도 4,278회이며, 나머지 240회는 중복값 7개를 검출하는 데 소요되었다.
  * 데이터 수 N에 대해 N의 제곱 비율로 비용이 발생하여 가장 비효율적이었다.
  * 트리 (BST 593회 / AVL 523회): 트리는 삽입 경로를 따라 내려가면서 탐색과 중복 검사를 동시에 수행하므로 N log N 수준의 높은 효율을 보였다.
  *  AVL이 BST보다 비교 횟수가 70회 적었던 이유는 트리의 높이가 낮게 유지되어 삽입 시 탐색하는 경로 길이가 더 짧았기 때문이다.
* 탐색 비용: 순차 탐색은 O(N)으로 평균 88.86회가 소요된 반면, 트리는 O(높이)로 각각 7.30회, 6.70회를 기록하여 트리가 배열 대비 약 12~13배 뛰어난 탐색 성능을 보였다.
* 한계점 및 고려사항:
  * 회전 연산 오버헤드 미반영: 본 과제의 비교 횟수 측정 조건에는 AVL 트리가 균형을 맞추기 위해 수행하는 회전, Balance Factor 계산, 높이 갱신 연산의 오버헤드가 제외되었다
